Which mode
for which game

Type a game to get the mode, the connection, and the thing that usually goes wrong. The M button on the controller glows the colour of the mode it's in — match the light to the answer.

The 15-second rule

  • Android, game supports controllers → HID first.
  • Android, game only knows Xbox or PlayStation → XInput over Bluetooth.
  • Android, no controller support at all → Mapping Mode.
  • iPhone or iPad, any native game → PS Mode. iOS has no mapping fallback.

Four ways to connect

Android native, by cable

  1. Plug the phone in, and enable OTG in Android settings if it asks
  2. Hold M + Home for 3 seconds until the light turns yellow-green
  3. Launch the game — or close and reopen it if it was already running

Xbox identity, over Bluetooth

  1. Switch to XInput — the light turns blue
  2. Double-press M, then hold Home for 3 seconds
  3. Pair with Xbox Wireless Controller in the phone's Bluetooth list
  4. Reopen the game

iPhone or iPad

  1. Switch to PS Mode — the light turns purple
  2. Try USB-C first
  3. If nothing happens, double-press M and pair with Wireless Controller

Android mapping

  1. Open the ABXY Game app and turn on Mapping Mode — the light turns orange
  2. Grant the overlay and accessibility permissions it asks for
  3. Build a profile for the game, then test it before you rely on it

When a game won't respond

In this order
  1. Take a thick case off and push the USB-C connector fully home.
  2. On Android, check OTG or USB accessories is enabled in settings.
  3. Check the M button colour actually matches the mode you meant. Mode and USB-versus-Bluetooth are two separate settings.
  4. For Bluetooth: double-press M, hold Home 3 seconds, forget the old pairing, pair again.
  5. Connect first, then launch. If the game was already open, force-close and reopen it.
  6. Look in the game's own controller settings. Some games take controller input in play but not in menus.
  7. If HID by cable fails on Android, try XInput over Bluetooth before you reach for Mapping Mode.
  8. Update the firmware, the app and the game. Rebuild mapping profiles after a game changes its HUD.

How to talk about it

Don't say

  • "GHOST X supports every Android and iOS game."
  • "PUBG and Free Fire officially support the controller."
  • "Mapping will never affect an account."

Say this

"GHOST X supports native controller games, and includes Android touch mapping for many touch-only titles. Compatibility depends on the game version, the device and the publisher's policy."
